Ingeniería del Modelo

Selección de Algoritmos

Se seleccionaron algoritmos supervisados de clasificación para predecir el nivel de riesgo de atención de usuarios.

Modelos candidatos:
  • Regresión Logística: modelo base para clasificación binaria
  • Random Forest: robusto ante ruido, útil para datos categóricos
  • XGBoost: boosting eficiente con buen desempeño
Criterios de selección:
  • Capacidad de interpretar importancia de variables
  • Manejo de desbalance entre casos críticos y no críticos
  • Velocidad de entrenamiento y predicción
Entrenamiento del Modelo

El modelo se entrenó con datos anonimizados y balanceados simulando los perfiles de riesgo.

Pasos:
  • División del dataset (80% entrenamiento, 20% prueba)
  • Codificación de variables categóricas (One-Hot Encoding)
  • Estandarización de variables numéricas
  • Entrenamiento con validación cruzada (k=5)
Riesgos mitigados:
  • Sobreajuste mediante early stopping
  • Validación cruzada para generalización
Ajuste de Hiperparámetros

Se optimizaron los hiperparámetros mediante GridSearch y RandomSearch.

Parámetros evaluados:
  • n_estimators, max_depth, min_samples_split (Random Forest)
  • learning_rate, subsample (XGBoost)
  • Penalty, C (Logistic Regression)
Herramientas usadas:
  • scikit-learn: GridSearchCV
  • cross_val_score para validación
Evaluación del Modelo

El modelo fue evaluado para garantizar su utilidad práctica en priorización de usuarios.

Métricas obtenidas:
  • Accuracy: 99.45%
  • Recall: 94.25% (detección de casos críticos)
  • F1-Score: 97.04%
  • ROC AUC: ≥0.98
Validación final:
  • Evaluación sobre conjunto de prueba realista
  • Simulación de saturación de agenda con datos históricos
  • Comparación con benchmark sin priorización
